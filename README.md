# HidroLife — Spas e Banheiras de Hidromassagem

Landing page de captação de leads da HidroLife (Santa Catarina). Não tem carrinho nem preços: todos os botões levam ao WhatsApp **(48) 99953-9186** com uma mensagem pronta.

## Stack
- HTML, CSS e JavaScript puros, sem etapa de build.
- GSAP + ScrollTrigger e Lenis, carregados via CDN.

## Rodar localmente
Sirva a pasta com qualquer servidor estático. Exemplo:

```bash
python -m http.server 5520
```

Depois abra http://localhost:5520.

## Deploy
É um site estático: basta publicar a raiz do repositório (Vercel, Netlify, Hostinger…). Não há comando de build nem pasta de saída.

## Conteúdo provisório (MVP)
- As fotos em `assets/img/provisorias/` são ilustrativas.
- Os prints em `assets/img/feedbacks/` são exemplos e serão trocados pelos prints reais de clientes.
